| B-3 | R-6 | `cost-head`를 두 줄로 분리(1행 이 세션·오늘 누적 / 2행 압축 절약·캐시 깨짐 손실) | 사용자가 준 5개 요구를 한 줄 4칸에 다 넣으면 R-5처럼 다시 밀려난다. 두 줄로 나누면 각 칸이 금액+단어, 건수(+소요시간) 두 줄을 여유 있게 갖는다 |
| B-3 | R-9 | 2열을 고정 px 대신 `justify-content:space-between`으로 우측 고정 | 사용자는 "px 지정"을 요청했지만 카드 폭이 반응형이라 고정 px는 폭이 바뀌면 다시 어긋난다. space-between이 "1열 길이와 무관하게 2열이 일정한 위치"라는 실제 목적을 더 안정적으로 만족한다 |
